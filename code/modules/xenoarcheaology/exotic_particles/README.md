# Xenoarcheology - Exotic Particles

This not-so-subtly named module is pretty much just a magic system masquarading
as some kind of science.

## Tuning

Projections with strength 100 are the highest things should generally go, as
this is what 'wow, that hit hard' is tuned to.

- Rapid hitting melee weapons being at 35-60 is probably fine.
- Rapid hitting projectiles being at 25-50 is probably fine.
- Hard hitting melee at 50-75 is probably fine.
- Hard hitting projectiles at 50-75 is probably fine.
- 100 is like, "really slow firing sniper rifle" or detonation levels. Spamming
this is not recommended.
- Anything over 100 can result in `comedy`.
